Zero Trust Architecture is a modern cybersecurity model based on the principle "never trust, always verify". 
Authenticates every user and device before they can access resources—whether they’re located within or outside the corporate network.

**Every access request is verified based on:**

User identity
Device health
Application being accessed
Location
Risk level
Data sensitivity

## **Core Principles of Zero Trust**

Verify identity – User authentication (MFA, certificates, CAC/PIV cards).
Verify device posture – Is the device compliant and secure?
Least-privilege access – Users get only the access they need.
Micro-segmentation – Networks and applications are separated into smaller protected zones.
Continuous monitoring – Access can be reevaluated during a session.
