**Due Care vs Due Diligence**
**Due Care**

Taking reasonable precautions.

Example:

Installing firewalls
Requiring MFA
Implementing antivirus

Management says:

"We need this security control."    -->   That is Due Care.

**Due Diligence**

Ensuring controls continue working.

Example:

Reviewing firewall logs
Auditing access
Vulnerability scanning
Penetration testing

Management says:

"Let's verify the control is effective."    -->    That is Due Diligence.

Due Care = Create

Create or implement the security control.

Due Diligence = Check

Check whether the control works.
