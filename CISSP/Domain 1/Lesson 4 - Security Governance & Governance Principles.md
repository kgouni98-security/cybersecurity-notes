**Think of governance as answering:**

"Who decides what security the organization needs?"

Security Governance ensures security aligns with the organization's objectives.

**Example**

"Our goal is to reduce ransomware attacks."

Security Governance determines:

Budget
Security policies
Responsibilities
Risk tolerance
Compliance requirements

The firewall engineer DOES NOT make these decisions.

Management does.

Exam Tip:

Governance = Direction

Management = Execution

Strategic	                              Operational

**Security Governance Principles**

There are five major principles.

1. Strategic Alignment           -->    Security should support business.
2. Risk Management               -->    Everything revolves around risk.       -->    The goal is NOT zero risk; The goal is acceptable risk.
3. Resource Management           -->    Security budgets are limited.
4. Performance Measurement       -->    How do we know security is working?    -->   Mean Time to Detect (MTTD); Mean Time to Respond (MTTR); Number of incidents; Patch compliance; Phishing click rate
5. Value Delivery                -->    Security must create business value.

**Organizational Roles**

**Board of Directors**
Highest authority.

**Responsibilities:**
Governance
Risk oversight
Strategy

**CEO**
Runs the business.
Owns overall business objectives.

**CIO**
Responsible for IT.

**Focus:**
Technology
Infrastructure
Business systems

**CISO (Very Important)**
**Responsible for:**
Information Security
Security strategy
Security governance
Security program

**NOT responsible for running IT.**

**Data Owner**

Frequently tested.

**Responsibilities:**
Classifies data
Determines access
Determines retention

**NOT IT.**

**Example:**
HR owns employee records.
IT stores them.

**Data Custodian**

Implements what the owner decides.

**Examples:**
Database Administrators
Storage Administrators
System Administrators

**Data User**

Uses the data according to policy.

**Examples:**
Employees
Contractors
